# Agence-Location-Java
Application console en Java de gestion d'une agence de location de véhicules (voitures, motos, utilitaires, luxe) : catalogue, clients particuliers et entreprises, contrats, tarifs avec remises, entretien et statistiques. Projet de programmation orientée objet : héritage, polymorphisme, classes abstraites, interfaces, Javadoc.
